## 1. Why should I use Myrikko?

Myrikko makes it easier to build with multiple frontier AI models through a single API, with intelligent routing, unified billing, and developer-friendly pricing.

With Myrikko, you can:
- Integrate once. Access multiple frontier AI models through a single API endpoint.
- Compare models easily. Evaluate and switch between models without maintaining separate provider integrations.
- Improve reliability. Automatically route requests based on provider latency and availability.
- Monitor usage in one place. Track usage, costs, billing, and request logs through a unified dashboard.
- Reduce AI API costs. Pay as you go with developer-friendly pricing and no platform markup.

## 2. Which AI models are available on Myrikko?

Myrikko provides access to a growing range of large language models from leading AI labs, including Moonshot AI, Zhipu AI, Anthropic, OpenAI, DeepSeek, Alibaba Cloud, and Google. Access and compare their models through a single API.

For the latest list of supported models, please visit the Model Marketplace page.

## 3. How frequently are new models added?

## 4. Which SDKs does Myrikko support?

Myrikko supports popular SDKs,including the OpenAI, Anthropic, and Google GenAI SDKs.

In most cases, you only need to update your API key, base URL, and model parameter to start sending requests through Myrikko.

Please refer to the Quickstart guide for SDK Integration setup examples.


## 5. How do I get started?

Get started with Myrikko in a few simple steps:

1. Create a Myrikko account.
2. Add credits to your account.
3. Create an API key or copy your default key.
4. Configure your API key and base URL.
5. Choose a model and start sending requests.

## 6. Do I need a separate API key for each model?

No.

A single Myrikko API key gives you access to our full range of supported models.


## 7. How is pricing calculated?

Pricing is based on the input and output tokens used by each request. Rates vary by model and are listed on the Model Marketplace page.
With pay-as-you-go pricing, you only pay for what you use.

## 8. Is there any platform markup?

No. Myrikko charges for the tokens you use at the model-specific rates listed on the Model Marketplace page, with no additional platform markup.

## 9. Where can I view my usage and costs?

You can monitor everything from the dashboard, including:

* API requests
* Token usage
* Costs
* Model usage

You can download your usage details from **Settings → Data & Account**.


## 10. What happens if a model provider becomes unavailable?

Myrikko automatically routes requests based on provider latency and availability. If a provider becomes unavailable, requests are redirected to another available provider offering the same model to maintain service reliability.

## 11. How does automatic routing work?

Myrikko intelligently selects an available provider based on factors such as availability, latency, and service health.
This helps improve reliability without requiring changes to your integration.

## 12. How is my data handled?

Myrikko processes API request data to deliver the requested service and support usage tracking, billing, service reliability monitoring, and abuse prevention.

For details on how your data is handled, retained, and deleted, please refer to our Privacy Policy.

## 13. Is data encrypted in transit?
Yes. Communication between your application and the Myrikko API is encrypted using HTTPS to protect data in transit.
